# 📈 Finance Projects

Personal portfolio of financial analysis projects using Python.

## 🔍 Projects

### Stock Returns Analysis
Analysis of 5 major tech stocks (AAPL, MSFT, GOOGL, AMZN, TSLA) from 2023 to 2024.

**What it does:**
- Downloads historical price data using yfinance
- Calculates daily returns
- Plots cumulative returns over time
- Generates descriptive statistics

**Tools:** Python, Pandas, Matplotlib, yfinance

## 🛠️ Tech Stack
- Python 3.11
- Pandas
- Matplotlib
- yfinance
